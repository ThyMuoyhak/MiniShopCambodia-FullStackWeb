# minishop_frontend_user

Mini Shop — customer storefront (Frontend_User).

A multi-shop e-commerce storefront for customers. Browse shops, view products,
check out with ABA Pay (KHQR), track orders and manage your profile.

## Setup

```bash
npm install
npm start
```

Runs on http://localhost:3000. The backend API defaults to http://localhost:8000
(override with the `REACT_APP_API_URL` environment variable).
