# minishop_frontend_admin

Mini Shop — Admin Panel (Frontend_Admin).

The platform admin controls everything: create/manage shops (status, expiry,
product & category limits), manage users, view activity logs, and perform full
backup & import (JSON / ZIP / Excel) plus per-shop data management
(products, orders, customers, categories).

## Setup

```bash
npm install
npm start
```

Runs on http://localhost:3001. The backend API defaults to http://localhost:8000
(override with the `REACT_APP_API_URL` environment variable).
