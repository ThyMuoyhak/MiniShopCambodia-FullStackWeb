# minishop_frontend_dashboard_user

Mini Shop — Shop Owner Dashboard (Frontend_Dashboard_User).

The dashboard where each shop owner manages their store: POS, products,
categories, stock, orders, customers, reports, receipts, shop settings,
ABA Pay, Telegram bot, and backup & import (JSON / ZIP / Excel).

## Setup

```bash
npm install
npm start
```

Runs on http://localhost:3002. The backend API defaults to http://localhost:8000
(override with the `REACT_APP_API_URL` environment variable).
